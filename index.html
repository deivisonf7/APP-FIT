Aeróbico

Enciclopédia Completa de Exercícios

1. Peitoral (Peito)
Porção Clavicular (Superior)
  • • Supino inclinado com barra
  • • Supino inclinado com halteres
  • • Supino inclinado articulado (máquina)
  • • Crucifixo inclinado com halteres
  • • Crucifixo inclinado na polia (cabos de baixo para cima)
  • • Flexão de braço inclinada (pés elevados no banco)
  • • Supino inclinado com pegada invertida
Porção Esternocostal (Médio e Geral)
  • • Supino reto com barra
  • • Supino reto com halteres
  • • Supino reto articulado (máquina vertical/convergente)
  • • Crucifixo reto com halteres
  • • Peck Deck / Voador
  • • Crossover na polia média
  • • Flexão de braço tradicional no chão
  • • Flexão de braço com carga (anilha nas costas)
Porção Costal (Inferior)
  • • Supino declinado com barra
  • • Supino declinado com halteres
  • • Supino declinado articulado
  • • Crucifixo declinado com halteres
  • • Crossover na polia alta (cabos de cima para baixo)
  • • Paralelas nas barras paralelas (tronco inclinado)
  • • Flexão de braço declinada (mãos no banco)
  • • Supino Guilford (na polia baixa)
2. Costas (Dorsais)
Latíssimo do Dorso / Grande Dorsal (Largura)
  • • Puxada frontal na polia alta (pegada pronada aberta)
  • • Puxada com pegada supinada (fechada ou média)
  • • Puxada com pegada neutra (triângulo)
  • • Puxada articulada unilateral
  • • Barra fixa tradicional (pegada pronada aberta)
  • • Barra fixa com pegada supinada (Chin-up)
  • • Barra fixa com pegada neutra
  • • Pulldown na polia alta com barra reta
  • • Pulldown na polia alta com corda
  • • Pullover com halter (em banco reto)
Miolo das Costas / Romboides e Trapézio Médio/Inferior (Espessura)
  • • Remada curvada com barra (pronada ou supinada)
  • • Remada curvada com halteres
  • • Remada baixa na polia com triângulo
  • • Remada baixa na polia com barra reta (pegada aberta)
  • • Remada cavalinho (barra em T)
  • • Remada articulada na máquina
  • • Remada no banco inclinado com halteres (Seal row)
  • • Remada unilateral com halter (Serrote)
  • • Crucifixo inverso na polia alta
Trapézio Superior
  • • Encolhimento de ombros com barra pela frente
  • • Encolhimento de ombros com barra por trás
  • • Encolhimento de ombros com halteres
  • • Encolhimento de ombros no Smith
  • • Remada alta com barra
  • • Remada alta na polia com corda
Lombar / Eretores da Espinha
  • • Levantamento terra tradicional
  • • Levantamento terra sumô
  • • Extensão lombar no banco romano
  • • Good Morning (bom dia) com barra
  • • Extensão lombar no chão (superman)

  • • Desenvolvimento com halteres

  • • Elevação lateral na máquina articulada
